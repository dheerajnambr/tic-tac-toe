## 🚀 Overview

This project is a creative and highly modern take on the classic Tic-Tac-Toe game. Instead of relying on heavy third-party GUI libraries like Tkinter or PyGame (which often require complex installations), this script acts as a dynamic generator. When executed, it generates a stunning, fully-featured HTML/CSS/JS frontend and automatically pops it open in your default web browser!

## 💎 Key Features

- **Zero External Dependencies:** Runs out-of-the-box on any machine with Python installed. No `pip install` required! It uses only standard libraries (`os`, `tempfile`, `webbrowser`). 📦
- **Stunning UI:** Features a modern dark mode theme with frosted glassmorphism elements, neon glows, and floating background orbs. 🌌
- **Rich Animations:** 
  - Dynamic, self-drawing SVG animated Tic-Tac-Toe icon in the header. ✏️
  - Popping and scaling effects for placing `X`s and `O`s. 💥
  - Glowing pulse animations for the winning line sequence. 🏆
- **Smart Engine:** Accurately detects wins, draws, and smoothly transitions turns between players. 🧠
- **Premium Branding:** Includes a sleek, animated "Designed by Dheeraj PT" watermark at the bottom right. ✍️

## 🛠️ How to Play

1. Open your terminal or command prompt.
2. Navigate to the project directory:
   ```bash
   cd path/to/python_test
   ```
3. Run the script:
   ```bash
   python3 tic_tac_toe.py
   ```
4. **Enjoy!** The script will automatically verify its built-in dependencies and pop open the beautiful interface directly in your default web browser!

## 🧩 Tech Stack Under The Hood

* **Backend Launcher:** Python 3 
* **Frontend UI:** HTML5 & CSS3 (Glassmorphism + Keyframe Animations + SVG)
* **Game Logic:** Vanilla ES6 JavaScript
